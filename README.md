# Vargas Portfolio

Responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Add your assets
Put these files in `assets/`:
- `logo.svg`
- `resume.pdf`
- `Record Management System preview.png`
- `bulsu.png`
- `sti.png`
- `marcelo.png`

The Brew Desk and E-JeepTrack cards use placeholder graphics until you add screenshots. Update project descriptions and GitHub links in `index.html` as needed.

The contact form currently uses `mailto:` and opens the visitor's email application. A backend or form service is required for submissions directly through the website.
